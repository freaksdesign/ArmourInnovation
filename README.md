# Armour Innovation LLC

Marketing site for Armour Innovation LLC, served by GitHub Pages at
[armourinnovation.com](https://armourinnovation.com).

Static HTML with no build step. Push to `main` and it deploys.

- `assets/css/site.css` design system, committed light theme
- `assets/js/site.js` mobile nav, scroll reveal, contact form
- `assets/fonts/` self-hosted Geist and Geist Mono, latin subset

## Contact form

`contact.html` posts to a form backend that is not configured yet. Until an
endpoint is set, the form tells the visitor it is not connected rather than
silently dropping the enquiry.
